# Suoni di chitarra

Le note in `classica/`, `acustica/` ed `elettrica/` sono registrazioni singole, una per nota, dal Mi basso (MIDI 40) al Mi acuto (MIDI 88). Il nome del file è il numero MIDI della nota.

**Non sono opera dell'autore di Guitarzorn e non ricadono sotto la licenza EUPL del progetto.**

- Origine: soundfont *FluidR3_GM* di Frank Wen, strumenti *Acoustic Guitar (nylon)*, *Acoustic Guitar (steel)* ed *Electric Guitar (clean)*.
- Resa in file per nota: progetto [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) di Benjamin Gleitzman.
- Licenza dei suoni: [Creative Commons Attribuzione 3.0](https://creativecommons.org/licenses/by/3.0/us/).
- Modifiche: nessuna al contenuto audio; i file sono stati solo rinominati con il numero MIDI.
